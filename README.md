# 第一年

一个网页上的文字模拟器，做成一部手机的样子。
你二十二岁，刚毕业，来到一座陌生城市，兜里八千块，要撑过九十天。

这一年里发生的事，全在手机里：微信、短信、来电、备忘录、钱包。谁跟你说了什么，你就得当场回一句。

剧本写在数据里，台词由模型即兴生成；没配模型也能玩，走预置台词。

---

## 怎么跑

**最简单：双击 `启动.bat`。** 它会自己开浏览器，地址是 <http://127.0.0.1:8010>。

命令行也行：

```bash
cd 第一年
python server.py          # 默认 8000
PORT=8010 python server.py
```

（Windows PowerShell 用 `$env:PORT=8010; python server.py`。）

端口被占用说明已经开着一个了，直接浏览器访问就行，不用再开第二个。

## 账号

- 注册 / 登录：用户名 3 到 20 个字，密码至少 6 位
- 登录状态存在浏览器本地，30 天有效，关掉浏览器再打开还在
- 昵称和头像存在服务器（SQLite），换台机器用同一个账号登录，名字头像跟着走
- 「我」页面最下面「退出登录」= 结束这个会话，回到登录页

密码不是明文存的：每个账号一个随机盐，PBKDF2-SHA256 迭代 12 万次后只存哈希。

## 界面里有什么

第一次打开先是账号页：注册一个用户名和密码（至少 6 位），账号存在本机的 `data/users.db` 里，不联网、不上传。注册完再给自己起个名字、挑一张头像（也可以用自己电脑上的图片）。名字会出现在微信聊天里、出现在「我」那一页；玩到一半想改，进「我」→ 头部那个「改」或者下面的「名字 / 头像」都行。

| 位置 | 是什么 |
|---|---|
| 桌面 | 时间、第几天、七个图标（微信／电话／信息／备忘录／钱包／相册／设置） |
| 微信 | 三个页签：会话、通讯录、我。会话上方可以按分组筛：家人／朋友／工作／房东·中介／陌生人 |
| 通讯录 | 九个联系人分五组，每个名字下面一句话，写清这个人是谁、怎么认识的 |
| 信息 | 银行到账、验证码、分期提醒。诈骗电话打来时，验证码会先落到这里 |
| 电话 | 通话记录。骗子打来是整屏来电，接或不接 |
| 备忘录 | 你给自己记的待办，随剧情变化 |
| 钱包 | 余额和每一笔流水 |
| 相册 | 这一年拍的几张照片，走到哪天解锁到哪天 |

手机上的每个动作都能自己点：消息来了会弹通知条，点一下进聊天；想回桌面就点屏幕最下面那条横线（和真手机一样，没有多余的返回按钮），回去随便翻别的 App。

## 怎么回话

打字不用先点输入框：进聊天页光标就在里面，发完一句光标还留在那儿，接着打就行。

聊天框下面会给出几句现成的选项，点一下就是你要说的话。**也可以不理选项，自己打字。** 你说的话会照常发给对面，模型照常接。

结算的时候，你这句自由发挥会被判回最近的那个选项，按那个选项加减钱和警惕指数（比如「你把押金理由写下来我签字」会按「要求书面写清扣款理由」结算）。完全不相干的，就按没选处理。

## 剧情怎么组织的

`data/story.json` 是时间轴：

- `contacts`：九个联系人，带分组、头像字、颜色、一句话备注
- `order`：十五步，每步写清**第几天、几点、哪个事件、找谁**，以及一段旁白（前情）
- `bridge_if`：旁白可以按标记分叉。比如签过租金贷，第 54 天那条旁白就变成「那份分期这周上了征信」

顺序是写死的，不随机。原因很实在：随机抽会把「退租」抽到「看房」前面，人看着就乱，人物也认不住。

```
第 1 天   妈     到站报平安
第 6 天   陈姐   看房（中介，让你交定金）
第 9 天   老周   看房（二房东，先说缺点）
第 12 天  老周   签合同（租金贷）
第 18 天  王主管 面试（不缴社保）
第 24 天  400…   假客服（验证码）
第 30 天  王主管 外包岗
第 38 天  妈     问你要不要打钱
第 46 天  阿哲   饭局
第 54 天  未知   征信修复
第 62 天  阿豪   月薪两万
第 70 天  妈     过年回不回来
第 76 天  李师傅 搬家坐地起价
第 80 天  老周   退租扣押金
第 86 天  陈姐   让你帮着劝下一个客户
```

同一个人会在不同阶段反复出现，前一次的选择会影响后一次的旁白——这是「人物不乱」和「剧情接得上」的来源。

## 模型：默认就接了

项目根目录有个 `.env`，里面一行 `DEEPSEEK_API_KEY=...`。服务启动时会自动读它，玩家的每一句话、每个角色的每一个回合，都是模型当场说的。`.env` 已经在 `.gitignore` 里，不会进仓库。

剧本里写的是**意图**，不是台词：

- `opening` 写「他想让你明白什么」，模型用自己的话说出来。同一关开三次，三句都不一样。
- `beats` 写「这一轮他要干什么」，模型照着演，不照着念。

所以顺序是死的，话是活的。

换模型或换服务商：

| 变量 | 默认 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 无 | 没配就走 `data/fallback.json` 兜底台词 |
| `LLM_BASE_URL` | `https://api.deepseek.com/chat/completions` | 换成别的兼容接口 |
| `LLM_MODEL` | `deepseek-chat` | 模型名 |
| `PORT` | `8000` | 端口 |

断网或者额度用完了，会自动切到兜底台词，页面上不报错，答辩可以现场拔网线演示。

## 自测

```bash
python test_auth.py     # 注册、重名、密码错、会话、改资料、退出，18 项
```


先起服务，然后：

```bash
python test_client.py   # 接口、结算、五个结局各打一遍
python test_flow.py     # 按时间轴走完 15 步，看结局
```

`test_flow.py` 开头会先自检剧本：事件有没有、联系人有没有、日期有没有倒流。

## 模型 Key 与管理员后台（2026-10-28）

- **每个账号用自己的 Key。** 注册页有一栏 `API Key`（sk-…）。服务端用 HMAC-SHA256 计数器流加密后存进
  `data/users.db`，明文不出服务端，前端只显示末四位。不填也能注册，但对话只走 `data/fallback.json` 的固定台词，
  不会调用模型。
- **注册时当场验 key。** 会拿它真打一次 `max_tokens=1` 的最小请求，验不过直接拒绝，避免库里躺着坏 key。
- **管理员账号。** `.env` 的 `ADMIN_USER` / `ADMIN_PASSWORD` 指定；启动时自动创建或补全，并把原来的
  `DEEPSEEK_API_KEY` 收到管理员名下。管理员的"测一次"和后台都用这把 key，玩家额度互不影响。
- **后台 `/admin`。** 管理员在"我"页点「后台」，或直接开 `/admin`：账号列表、每人调用次数、key 状态（已配/没填）、
  封禁与解封、清掉某人的 key、改角色、一键测模型连通性。
- **`KEY_SECRET` 是加密主密钥，不要改、不要提交。** 改了以后库里已存的 key 全部解不开（用户要重填）。
- 自测：`python test_admin.py`（32 条，自己起临时实例、临时库）；`python smoke_live.py`（真库真 key 冒烟）。
